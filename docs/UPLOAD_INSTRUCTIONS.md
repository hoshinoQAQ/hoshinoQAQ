# 上传说明

把这个压缩包解压后，将里面的文件上传到你的 `hoshinoQAQ/hoshinoQAQ` 仓库根目录。

最终仓库结构建议是：

```text
hoshinoQAQ/
├─ README.md
└─ assets/
   ├─ profile-dashboard.png
   ├─ profile-dashboard.svg
   └─ source-parts/
      ├─ ...
```

最重要的是 `README.md` 和 `assets/profile-dashboard.png`。  
README 里现在只引用完整大图，手机端不会再因为表格布局被挤坏。

`assets/source-parts/` 里放的是之前生成的小图素材，暂时不在 README 里引用，后面要继续精修时可以再用。
