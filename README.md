## 🪄 Design Notes

这个主页的视觉重点不是把内容堆满，而是形成层次：第一屏用横幅、头像和打字动画建立印象；第二屏用状态卡、技能栈和统计数据说明能力；第三屏用精选项目和活动展示可信度；最后用贡献图、留言和互动页面入口增加记忆点。
